# Accident Prevention Analysis Dashboard | SQL & Power BI

## Project Overview

This is an end-to-end Data Analytics project developed using SQL and Power BI to analyze road accident data and identify patterns that can support accident prevention strategies.

The project focuses on understanding accident trends, severity levels, road categories, weather conditions, and contributing factors. Interactive dashboards and visualizations were created to transform raw data into actionable business insights.

---

## Tools & Technologies

* SQL
* Power BI
* DAX
* Power Query
* Excel

---

## Project Workflow

### 1. Data Collection

Collected and prepared accident-related datasets for analysis.

### 2. Data Cleaning & Transformation

Performed data cleaning and preprocessing using SQL and Power Query to ensure data quality and consistency.

### 3. SQL Analysis

Executed SQL queries to analyze accident trends, severity distribution, casualties, weather conditions, and road categories.

### 4. Dashboard Development

Built an interactive Power BI dashboard with KPIs, slicers, and visualizations to support data-driven decision-making.

### 5. Business Insights & Recommendations

Generated actionable insights and recommendations to improve road safety and reduce accident risks.

## Key Insights

* Minor accidents represent the largest share of reported incidents.
* Urban roads experience the most accidents.
* Accident frequency peaks during night hours.
* Driver distraction remains a major contributing factor.
* Accident distribution is highly uniform across all weather conditions, indicating visibility is not the primary driver.

---

## Recommendations

* Strengthen monitoring on high-risk urban corridors.
* Increase awareness programs on distracted driving.
* Improve street lighting in accident-prone areas.
* Enhance night-time traffic enforcement.
* Promote targeted road safety campaigns.
